Read the absolute scores. Small windows can fail generation. SWA’s RULER advantage still leaves a large gap to full attention; QRWKV7 wins this BABILong case. The 256K efficiency plot is a four-layer microbenchmark, not evidence of recall at that length.

02

Where the deployed models are

The same nine months, the same denominators. Switch between traffic share, absolute volume and growth to avoid mistaking a small starting point for market dominance.

Local/global mix is not pure SWA adoption. This group identifies reviewed checkpoint architectures, including global layers; it does not establish whether an endpoint runs the paper’s SWA + sinks intervention. Linear hybrids combine recurrent updates with attention. Mamba hybrids are a separate family. These are serving traffic groups, not the paper’s two controlled interventions.

      03

      A smaller state changes the curve

      Illustrative accounting · equal attention dimensions · no quality or throughput equivalence implied

      Full-attention layers still accumulate KV in a hybrid. A local window caps its own KV; a recurrent layer keeps a fixed state. Optional historical memories, prefix snapshots, and speculative branches add separate terms.

      Design State at 128K · one sequence What grows with context?
      Full attention 16 GiB All 32 layers’ KV
      All-layer SWA 64 MiB Nothing beyond the 512-token window
      All-layer recurrence 32 MiB Nothing in the assumed fixed state
      Local / full hybrid 4.047 GiB 8 full layers’ KV
      Recurrent / full hybrid 4.023 GiB 8 full layers’ KV

      Default: 32 layers; 8 KV heads × 128 dimensions; 2 bytes per scalar; 512 retained tokens; 1 MiB recurrent state per layer; 8 full layers in each hybrid. These are hypothetical dimensions, not a named model’s configuration. K/M ticks below use powers of two.

      Equations and exclusions

      Per-layer KV bytes per retained token: k = 2 × KV_heads × head_dimension × scalar_bytes = 4,096 . With context N , layers L , full layers F , window w , recurrent bytes per layer R , and sequences B :

      • Full: B × L × k × N
      • SWA: B × L × k × min(N,w)
      • Recurrent: B × L × R
      • Local/full hybrid: B × [F × k × N + (L−F) × k × min(N,w)]
      • Recurrent/full hybrid: B × [F × k × N + (L−F) × R]

      R must include all persistent recurrent and convolution state in a real deployment. Excludes weights, activations, workspace, allocator slack, multimodal encoders, extra history, prefix snapshots and speculative branches. Active state alone is not total GPU memory. No bandwidth or storage-demand estimate is inferred.

      Real local/global example. Gemma 3 mixes local and global softmax attention. Its global layers keep a context-dependent cache.

      Real recurrent/global example. Qwen3-Next uses three Gated DeltaNet layers per gated attention layer. It retains recurrent state and attention KV. Its dimensions differ from this illustration.

      04

      Find the cheapest memory that meets the task

      An open research test sequence for memory caching and systems projections

      Memory caching is the optional retention and retrieval of useful model history beyond the active window or recurrent state. In this comparison, it includes historical state anchors and memory banks as well as conventional KV reuse. The next question is how much quality each retained byte buys, and where that byte can live.

      Phase Question and comparison Decision evidence
      1 · Recall baseline Which tasks actually lose quality? Compare full attention, SWA with sinks, a native GDN hybrid, and a retrofit. Use matched teachers for intervention studies; report native checkpoints separately. Sweep fact age, distractors, number of facts, context and generation length. Measure exact retrieval, multi-hop answers, code and agent success. Preserve full-attention scores.
      2 · Equal budgets At equal active bytes and latency targets, which design retains the most useful history? Sweep windows, recurrent capacity and full-layer fractions. Publish quality–memory frontiers, prefill cost, decode throughput and p95 latency on the same serving stack.
      3 · Optional memory Do MARCH-style anchors, Memory Cache ideas, or Mixture of Memories repair a measured deficit on GDN? Does the same budget help SWA? Add one mechanism at a time. Include metadata, lookup and write costs; test stale anchors, eviction, multiple sessions and adversarial fact placement. Only then test combinations and Titans/Atlas references.
      4 · Placement Can useful history move from HBM to DRAM or NAND while meeting the quality and latency target? Replay arrival traces. Measure bytes per snapshot, reuse distance, restore rate, read amplification, bandwidth, endurance, energy, concurrency and tail latency. Compare recomputation against restoration.

      HBM and DRAM. Active KV and recurrent state compete with weights for capacity and bandwidth. Cheaper state can increase concurrency. Idle sessions and reusable snapshots may create a host-memory tier; measure restore deadlines before sizing it.

      NAND and storage. Persistent history may create a capacity opportunity only when reuse and latency justify it. Fixed active state can shrink the cache opportunity per session, while optional memories can expand retained history. Memory and storage projections must account for both effects.

      Independent demand signal · OpenRouter

      Repeated context makes retention worth testing

      Cache is Crucial reports cached prompt tokens rising from about 60% of all agentic tokens in January to just under 90% in September. That measures reuse in OpenRouter’s agentic cohort; it does not reveal HBM, DRAM or NAND placement.

      Its cohort differs from the public rankings above. Do not multiply its cache rate by these token totals. Context Demand , Cache Telemetry , Hybrid Checkpoints and I/O Projections provide the related demand and systems views.

      Closed models remain an evidence boundary. Public token counts and advertised context windows do not reveal a model’s attention operator, retained history, or serving policy. Keep unresolved traffic visible; compare API quality and latency separately from architecture claims. Architecture projections should carry that uncertainty rather than assign it to either design.

      05

      What is measured, and what is not

      A reproducible comparison with explicit evidence boundaries.

      Aligned public observations

      All six datasets use complete UTC calendar months from January through September 2026. Daily rankings expose up to 50 named models plus an aggregated tail. Input and output tokens count toward traffic; private activity is outside this public view.

      Exact identities, reviewed sources

      Architecture and attention style come from versioned registries with model-specific evidence. Names, context limits and closed-model performance do not establish architecture. Unresolved models stay in the denominator.

      Comparison, not attribution

      Traffic growth reflects adoption, model releases, routing and pricing as well as architecture. The paper tests particular checkpoints under particular memory budgets. Neither observation proves a universal quality ranking.

      Memory and storage still need traces

      Token totals do not reveal resident bytes, concurrent sessions, idle periods, cache hits or restore latency. Those measurements connect useful recall to HBM, DRAM and NAND requirements.
