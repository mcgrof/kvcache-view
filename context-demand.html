04

What this means for memory systems

A workload signal to guide experiments and product planning.

Test useful recall

More traffic in a context bucket identifies a workload to study. Measure whether regular attention, linear hybrids and optional memory preserve the information needed to complete tasks.

Measure state reuse

Repeated prefixes and session history can make retained state valuable. Measure bytes per state, concurrent sessions, idle gaps and the cost of rebuilding that state.

Establish the storage case

HBM, DRAM and NVMe requirements depend on retention, placement and restore latency. Token traffic alone cannot determine offload capacity or bandwidth.

05

Sources, coverage and reproducibility

Observed public traffic

Daily OpenRouter rankings, filtered to text output. Each query returns up to 50 named models plus an aggregated “other” row. Both count toward total traffic. Private traffic is outside this public view; OpenRouter is not a census of the inference market.

What remains unknown

The API does not specify exact context-bucket boundaries or whether context classification uses input alone. It does not provide request counts, prompt-length percentiles, cache split, unique stored bytes or offload activity. Provider tokenizers differ.

A reproducible comparison
